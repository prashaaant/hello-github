# hello-github

My first GitHub repository, created while learning Git and GitHub. It now also holds a few small Arduino experiments from my early hardware days.

## Contents

| Path | What it is |
| --- | --- |
| `arduino/led_blink/` | Blinks an LED on pin 13 once per second. |
| `arduino/bluetooth_led/` | Reads characters from a Bluetooth module over serial (`F` / `B`) and switches LEDs on pins 4 and 3. |
| `notes/godmode.md` | Note on creating the Windows "God Mode" folder. |
| `archive/` | Original first test files from when I was learning Git. |

## Running the Arduino sketches

1. Open the `.ino` file in the Arduino IDE.
2. Select your board and port.
3. Upload.
