# Quick Installation Guide

## How to Install the Content Tracker Chrome Extension

### Step 1: Download the Extension
1. Download all the extension files to a folder on your computer
2. Make sure you have these files:
   - `manifest.json`
   - `background.js`
   - `content.js`
   - `popup.html`
   - `popup.js`
   - `options.html`
   - `icons/` folder with icon files

### Step 2: Load in Chrome
1. Open Google Chrome
2. Go to `chrome://extensions/`
3. Turn on "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the folder containing the extension files
6. The extension should now appear in your extensions list

### Step 3: Start Using
1. Click the extension icon in your toolbar (you may need to pin it first)
2. Start browsing websites normally
3. The extension will automatically track and categorize your browsing
4. View your statistics by clicking the extension icon

### Troubleshooting
- If the extension doesn't load, check that all files are in the same folder
- Make sure Developer mode is enabled
- Try refreshing the extension if it's not working properly

### Privacy Note
All your browsing data is stored locally on your device. Nothing is sent to external servers.

Enjoy tracking your browsing patterns! 📊
